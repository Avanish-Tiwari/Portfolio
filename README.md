# Avanish Tiwari — Portfolio

Personal portfolio built with Vite and React.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run dev` serves the site locally. `npm run build` writes static files to `dist`, which Netlify publishes. Client-side routes fall back to `index.html` via `netlify.toml`.

## Content

Profile copy, project links, and skills live in `src/data/profile.js`. The downloadable resume is `public/resume.pdf`.
